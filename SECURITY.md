# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Security** tab and select **Report a vulnerability** if private vulnerability reporting is enabled. Otherwise, contact the maintainer privately through their GitHub profile. Include the affected version, reproduction steps, and potential impact.

You should receive an acknowledgement within seven days. Please allow time for a fix and coordinated disclosure before publishing details.

## Scope

Security reports about Stats and its installer are in scope. Vulnerabilities in Amp, Codex, SwiftTerm, Rust crates, or other dependencies should also be reported to the relevant upstream project.
